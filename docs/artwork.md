# Website artwork

Two project assets were generated with the built-in image generation tool using the imagegen skill. Transparent backgrounds were requested. ImageMagick encoded WebP display copies; the original generated PNGs remain in the generation output directory. The supplied Optimedicate microscope artwork was kept unchanged.

## WACentral

Final asset: `src/assets/wacentral-artwork.webp`

Prompt:

> A single high-end 3D product icon for WACentral, a business messaging API gateway. A substantial emerald green rounded-square chat tile with a white speech-bubble relief, connected behind it to three smaller silver metallic rounded-square nodes by short elegant gold connector bars. Small composition with tactile machined dark graphite edges, glossy green ceramic face, realistic depth and beveled corners. Studio-rendered premium technology product illustration, soft upper-left lighting, three-quarter frontal perspective, finely controlled highlights. Isolated centered object on true transparent background, generous transparent margin. No letters, no typography, no numbers, no logos of existing companies, no phone screenshots, no fake interfaces. Crisp and beautifully crafted, designed to accompany a detailed blue 3D microscope illustration on a product website. Square image.
